# Field `col` — Backend contract

> **هدف:** قرارداد کامل مقدار `field.col` که بک‌اند می‌فرستد تا فرانت بتواند عرض فیلد را در فرم، کارت، و لایه‌های ریسپانسیو **کامل** کنترل کند.
>
> **Resolver:** `lib/helpers/fieldCol.js` → `resolveFieldColProps(raw)` → props برای `<Col />` آنت دیزاین.
>
> **وضعیت:** پیاده‌سازی‌شده طبق این سند.
>
> **ریسپانسیو:** فقط آبجکت (`{ xs, sm, md, … }`). آرایه پشتیبانی نمی‌شود.

---

## 1. نقش `col`

`col` فقط **عرض ستون** فیلد داخل `Row`/`Col` را مشخص می‌کند؛ نه ترتیب، نه offset، نه visibility.

| کجا استفاده می‌شود | رفتار |
|--------------------|--------|
| فرم (`FormGroup`) | عرض هر فیلد در گرید فرم |
| کارت ایندکس (`IndexCardsBody`) | عرض هر فیلد داخل کارت |

پیش‌فرض اگر `col` نباشد / نامعتبر باشد: **یک ردیف کامل** (`span: 24` در همهٔ بریک‌پوینت‌ها وقتی `defaultFull`، یا فقط تا `md` در فرم).

---

## 2. انواع مقدار (خلاصه)

```
col =
  | null | undefined          → full (پیش‌فرض)
  | number                    → گرید 1–24 یا 0=auto
  | keyword                   → "auto" | "fill" | "full"
  | size string               → CSS width / flex ("100px", "50%", "12rem", …)
  | span string               → "1" … "24" (مثل عدد)
  | ResponsiveObject          → per-breakpoint ({ xs, sm, md, lg, xl, xxl })
```

همهٔ شکل‌ها در نهایت به یکی از این‌ها روی `<Col>` می‌رسند:

- **Grid span** → `xs` / `sm` / `md` / `lg` / `xl` / `xxl` (عدد ۱–۲۴)
- **Flex / fixed width** → `flex` + در صورت نیاز `style` (`width`, `maxWidth`, `minWidth`)

---

## 3. مقادیر اسکالر (یک مقدار برای همهٔ عرض‌ها)

### 3.1 عدد — گرید ۲۴ستونی (legacy)

| مقدار | معنی | خروجی تقریبی Col |
|------:|------|------------------|
| `1` … `24` | سهم از ۲۴ ستون | از بریک‌پوینت پایه به بالا همان span؛ زیر آن معمولاً `24` (تمام‌عرض موبایل) |
| `0` | عرض محتوا (auto) | `flex: "none"` + `width: auto` |

```json
{ "col": 12 }
{ "col": 8 }
{ "col": 0 }
```

> اعداد خارج از `0…24` (مثلاً `48`) → clamp به `24`. توصیه: بک‌اند فقط `0–24` بفرستد.

### 3.2 کلیدواژه

| مقدار | معنی | معادل / خروجی |
|-------|------|----------------|
| `"auto"` | عرض محتوا | مثل `0` → `flex: "none"` |
| `"fill"` | فضای باقی‌ماندهٔ ردیف را پر می‌کند | `flex: "auto"` (کنار `auto` / سایز ثابت می‌نشیند) |
| `"full"` | تمام ردیف | مثل `24` روی همهٔ بریک‌پوینت‌ها |
| `"0"` | مثل عدد `0` | auto |

```json
{ "col": "auto" }
{ "col": "fill" }
{ "col": "full" }
```

کلیدواژه‌ها **case-insensitive**اند: `"Auto"`, `"FILL"`, `"Full"` هم قبول.

**مثال چیدمان fill:** فیلد `a` بقیهٔ ردیف را می‌گیرد، `b` به اندازهٔ محتوا، `c` خط بعد:

```json
[
  { "name": "a", "col": "fill" },
  { "name": "b", "col": "auto" },
  { "name": "c", "col": "full" }
]
```

### 3.3 رشتهٔ سایز CSS (ثابت / درصدی / واحدها)

هر رشتهٔ غیرکلیدواژه و غیرعددِ خالص → عرض با `flex`، نه span گرید:

| مثال | معنی |
|------|------|
| `"100px"` | عرض ۱۰۰ پیکسل |
| `"12rem"` / `"2em"` | واحد نسبی فونت |
| `"50%"` | نصف عرض والد (Row) |
| `"33.333%"` | حدود یک‌سوم |
| `"20vw"` / `"40vh"` | نسبت به viewport |
| `"min(100%, 320px)"` | عبارت CSS مدرن |

```json
{ "col": "100px" }
{ "col": "50%" }
{ "col": "min(100%, 280px)" }
```

**خروجی:**

```js
{
  flex: "0 0 100px",
  style: { maxWidth: "100%" }
}
```

### 3.4 رشتهٔ فقط‌عدد (span به‌صورت string)

```json
{ "col": "12" }
{ "col": "6" }
```

مثل عدد متناظر — **بدون واحد** ⇒ گرید، نه CSS.

### 3.5 تشخیص string

| الگو | تفسیر |
|------|--------|
| `/^(auto\|fill\|full)$/i` | کلیدواژه |
| `/^\d+(\.\d+)?$/` | span عددی (سپس clamp ۱–۲۴؛ `0` → auto) |
| هر رشتهٔ دیگر | سایز CSS → flex |
| بقیهٔ تایپ‌ها / آرایه | نامعتبر → fallback full |

## 4. ریسپانسیو — آبجکت

کلیدها = بریک‌پوینت‌های Ant Design. هر value می‌تواند همان اسکالر بخش ۳ باشد (عدد، keyword، size string).

```json
{
  "col": {
    "xs": 24,
    "sm": 24,
    "md": 12,
    "lg": 8,
    "xl": 6,
    "xxl": 6
  }
}
```

با مخلوط span و CSS / fill:

```json
{
  "col": {
    "xs": "full",
    "md": "50%",
    "lg": 8,
    "xl": "auto"
  }
}
```

```json
{
  "col": {
    "xs": "full",
    "md": "fill"
  }
}
```

### قوانین آبجکت

1. **بریک‌پوینت‌های مجاز:** `xs` | `sm` | `md` | `lg` | `xl` | `xxl`
2. کلید ناشناخته نادیده گرفته می‌شود.
3. **Cascading موبایل‌فرست:** اگر فقط `md` و `lg` داده شود، زیر `md` پیش‌فرض `full` (۲۴) است مگر `xs`/`sm` صریح باشد. از هر کلید تعریف‌شده به بالا همان مقدار تا تعریف بعدی ادامه دارد.
4. مقدار هر کلید مستقل parse می‌شود؛ برای CSS / auto / fill روی آن bp مقدار `{ flex: … }` به Col داده می‌شود.

### فقط چند بریک‌پوینت

```json
{ "col": { "md": 12 } }
```

زیر `md` → full (`24`)؛ از `md` به بالا → `12`.

```json
{ "col": { "lg": "200px" } }
```

زیر `lg` → full؛ از `lg` → عرض ۲۰۰px.

## 5. جدول تصمیم (resolver)

```
raw is null/undefined/""     → fallback (full policy)
raw is array                 → نامعتبر → fallback
raw is plain object          → map keys xs..xxl + cascade
raw is 0 / "0" / "auto"      → auto (flex none, width auto)
raw is "fill"                → fill (flex auto)
raw is 24 / "24" / "full"    → full (all bp span 24)
raw is number 1..23          → span (with mobile-full base policy)
raw is numeric string 1..23  → same as number
raw is other string          → flex: 0 0 <size>; maxWidth 100%
else                         → fallback
```

### سیاست موبایل برای span اسکالر

- اسکالر عددی (`12`) ⇒ `xs/sm/md = 24` و از `lg` (یا `md` اگر `from: "md"`) به بالا = همان span.
- در حالت ریسپانسیو صریح (object) ⇒ همان چیزی که بک‌اند گفته (+ cascade).

`resolveFieldColProps(raw, { from, defaultFull })`:

| مصرف‌کننده | options |
|------------|---------|
| `FormGroup` | پیش‌فرض (`from: "lg"`, `defaultFull: false`) |
| `IndexCardsBody` | `{ from: "md", defaultFull: true }` |

## 6. مثال‌های بک‌اند (چیدمان‌های رایج)

| سناریو | `col` |
|--------|--------|
| نصف ردیف دسکتاپ | `12` |
| یک‌سوم دسکتاپ | `8` |
| تمام عرض | `24` یا `"full"` |
| چسبیده به محتوا (دکمه، چک‌باکس) | `0` یا `"auto"` |
| پر کردن باقی‌مانده کنار sibling | `"fill"` |
| عرض ثابت اکشن | `"120px"` |
| نصف نسبی همیشه | `"50%"` |
| موبایل full، تبلت نصف، دسکتاپ یک‌چهارم | `{ "xs": 24, "sm": 24, "md": 12, "lg": 6 }` |
| موبایل full، از md نصف با درصد | `{ "xs": "full", "md": "50%" }` |
| دسکتاپ fixed، موبایل full | `{ "xs": 24, "lg": "280px" }` |
| a پر می‌کند + b محتوا + c خط بعد | `a: "fill"`, `b: "auto"`, `c: "full"` |

---

## 7. چیزهایی که عمداً خارج از `col`اند

| نیاز | پیشنهاد جدا |
|------|-------------|
| `offset` / فاصله از چپ | `options.colOffset` یا آبجکت Col کامل جدا |
| `order` / ترتیب بصری | `options.colOrder` |
| مخفی کردن در یک bp | `options.hidden: { xs: true }` یا CSS |
| `pull` / `push` | پشتیبانی نشود مگر درخواست صریح |
| آرایه ریسپانسیو | پشتیبانی نمی‌شود — فقط object |

---

## 8. سازگاری عقب‌رو

| قبلاً | بعداً |
|-------|--------|
| `col: 12` | بدون تغییر رفتار |
| `col: 0` | بدون تغییر (auto) |
| missing | fallback قبلی فرم / کارت |
| مقدار جدید (`"auto"`, `"fill"`, `"100px"`, `{…}`) | رفتار جدید طبق این سند |

---

## 9. تست‌های پذیرش

- [x] `12` → دسکتاپ نصف، موبایل full
- [x] `0` / `"auto"` → عرض محتوا
- [x] `"fill"` → `flex: auto`
- [x] `"full"` / `24` → همیشه تمام ردیف
- [x] `"100px"` / `"50%"` → عرض CSS با `maxWidth: 100%`
- [x] `{ md: 12, lg: 8 }` → زیر md full + cascade
- [x] مخلوط `{ xs: "full", md: "50%", lg: 8 }`
- [x] نامعتبر (`true`, `"foo"` به‌عنوان size، `[]`, `{}`) → size یا fallback امن
- [x] فرم و کارت ایندکس هر دو از یک resolver

> رشتهٔ ناشناخته مثل `"foo"` به‌عنوان CSS size پذیرفته می‌شود (طبق قرارداد «هر استرینگ دیگر»).

---

## 10. جمع‌بندی برای بک‌اند

1. اسکالر: عدد `0–24` + `"auto"` / `"fill"` / `"full"` + هر CSS size string
2. ریسپانسیو: فقط **object** با کلیدهای `xs…xxl`
3. هر value داخل object همان اسکالرها را می‌پذیرد
